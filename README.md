# FinTrust Digital Bank – Data Analytics Solution

## 📊 Project Overview

This project presents the final Data Analytics solution developed for the **FinTrust Digital Bank Experience Lab**.

The project focuses on analyzing digital banking transactions, customer activity, transaction channels, transaction performance, and risk patterns using **SQL, Python, and Power BI**.

The final solution combines technical analysis with business validation to transform transaction data into actionable business insights and recommendations.

---

## 🎯 Project Objectives

The objectives of this project were to:

- Analyze customer and transaction performance
- Evaluate transaction success across different channels
- Identify transaction value and volume patterns
- Analyze customer segments and activity levels
- Examine risk-review patterns
- Validate key business findings using independent analytical methods
- Develop an interactive Power BI dashboard
- Translate analytical findings into actionable business recommendations

---

## 🛠️ Tools & Technologies

- **SQL / PostgreSQL** – Data analysis and business queries
